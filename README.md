# domain-filter

自维护的网络分流规则仓库。规则内容在本仓库修改，GitHub Actions 只把仓库内
Surge 规则转换为 sing-box 原生版本，不下载或同步第三方规则列表。
维护方式见 [sing-box 规则说明](singbox/README.md)。
